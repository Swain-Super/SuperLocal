# 局域网里用固定名字进入

别人不必先复制 IP。服务在局域网登记主机名 `superlocal.local`，浏览器打开 `http://superlocal.local:<端口>/` 就进入现在的聊天页。桌面窗口同时放一个二维码，扫出来的是同一服务的 `http://<局域网 IPv4>:<端口>/`。两种地址都直接进聊天，没有选择页。

本设计改掉《同一端口同时提供 HTTP 和 HTTPS》里「`http://` 页面不显示语音、视频、共享屏幕」这一条。信令仍不在 HTTP 上建立通话或屏幕共享。

## 名字

服务进程负责广播，桌面程序只显示。`-tls=false` 时同样广播。不新增命令行参数，不占用 80 端口。

只登记主机名的 A 记录，指向本机当前全部可分享的局域网 IPv4。可分享的范围和桌面访问地址相同：不要回环、不要 `169.254.`、不要 IPv6。浏览器不会去搜索服务类型，所以只广播类型而不登记这个主机名不算完成。

启动时按顺序挑选还没被别人占用的名字：

1. `superlocal.local`
2. `superlocal-2.local`
3. 一直到 `superlocal-9.local`

某个名字没有 A 记录，或者 A 记录全是本机这些 IPv4，就用它。A 记录里出现别人的地址，就换下一个。九个都被占时不广播名字，二维码仍可用。进程活着时不改名字。每 15 秒核对一次 IPv4，集合变了就更新 A 记录。服务停止时撤销广播。

没有可分享的 IPv4 时不广播，桌面也不显示名字和二维码。

`cfg.TLS` 为真时，自签证书的 DNS 名包含 `localhost` 和这次选中的名字。名字不在现有证书里时重新生成。`-tls=false` 不生成证书。

启动输出在地址列表之后、账号之前增加一行，例如 `名字 superlocal.local`。这一行不是 `http://` 地址，不进入按 IP 排列的聊天地址和后台地址。没有名字时不打印这一行。

## 桌面窗口

访问地址区域单独显示局域网名字，文案是 `http://<名字>:<端口>/`，可以复制。二维码画在这一区，内容是地址列表里第一条局域网聊天地址中的 `http://` 那条。点「刷新」后，窗口里的名字、地址和二维码按当前网卡重画。广播仍由服务每 15 秒更新，刷新按钮不负责重新登记。

没有局域网地址时，这一区和现在一样显示「当前没有局域网地址」。

「打开聊天」和「打开后台」仍打开 `https://127.0.0.1:<端口>`。

二维码由桌面程序自己生成。不给聊天页加依赖。

## 页面

`https://` 上的单聊和现在一样，点「语音」「视频」「共享屏幕」就发起。

`http://` 且 `GET /api/features` 的 `calls` 为真时，单聊仍显示这三个按钮。点任何一个都不发 `call.*` 或 `screen.*`，不打开浮层。三个按钮共用一条说明：「语音、视频和共享屏幕需要用 HTTPS 打开」。说明里给出把当前页面协议换成 `https:` 后的完整地址，主机和端口不变，可以复制。例如当前是 `http://superlocal.local:18080/` 时，地址是 `https://superlocal.local:18080/`。

`calls` 为假时不显示这三个按钮，包括 `-tls=false`。群聊不显示。`http://` 页面收到 `call.*` 或 `screen.*` 仍忽略。服务对非 TLS 连接上的这两类信令仍拒绝。
