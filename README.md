# SuperLocal

同一局域网里的即时聊天。一台电脑跑服务，其他人用浏览器打开地址就能进，不用装客户端，消息和文件也不出这个网络。

服务是一个 Go 进程，浏览器通过 HTTP 和 WebSocket 跟它说话。默认监听 `:8080`，数据放在 `-data` 指定的目录里。

## 特点

- **浏览器就是客户端。** 手机、平板、电脑打开同一个地址。窄屏上会话列表和聊天分成两屏，横屏和矮窗口会收紧工具栏，页面本身不滚动，只有消息列表滚动。
- **每个窗口一个账号。** 登录态放在当前标签页里。同一个浏览器再开一个窗口，可以登录另一个 Key，互不顶掉。
- **人在局域网里，数据也在。** 服务绑在本机，聊天、文件、截图和录屏都经这台机器转发，浏览器之间不建立直连。
- **输入区按日常聊天来做。** 平时一行，写给谁、表情、@、截图和发送都在手边；排版、代码、取色这些点开才出现。
- **消息只留 48 小时。** 启动时清一次，之后每 48 小时再清一次。单文件默认最大 200MB。

## 功能介绍

### 进门

用 Key 和昵称注册。Key 是 8–64 位字母、数字、下划线或连字符，没有单独的聊天密码，拿到 Key 的人就是这个用户。自己能看见自己的 Key，别人只看见昵称。

登录页可以分别随机生成 Key 和昵称，也可以一键注册，生成后直接进入。

### 会话

单聊和群聊。会话可以置顶、免打扰、搜索聊天记录。未读增加时，如果当前不在这个会话或页面不在前台，会用系统通知提醒。右上角显示到服务器的往返延迟。

群有群标识和群号（会话 ID 末 6 位）。群主可以添加、移出成员；任何人可以退出。成员列表能看到群主、在线和个性签名，右键可以发消息、@ 或移出。

### 消息

文字、图片、文件、表情回应、引用回复。自己的消息 24 小时内可以撤回。文字可以转发给其他会话。图片可以放大看。会话里会标出「以下为新消息」。

代码用围栏书写，气泡里是带语言名、行号和复制按钮的代码卡片。粘贴图片会直接当文件发送。

个人免打扰打开后，其他人不能再给这个人发单聊；本人仍可以发，群聊不受影响。

### 输入框

占位是「发送给 当前会话」。右侧一排按钮：

| 按钮 | 作用 |
| --- | --- |
| Aa | 加粗、删除线、斜体、下划线、列表、引用、链接、代码，以及字体、字号、颜色、高亮、对齐 |
| 表情 | 最常使用和默认表情 |
| @ | 在群里选择成员，也可以直接输入 `@` |
| 截图 | 提取文字、滚动截图、录屏、截图 |
| + | 图片、文件、聊天记录、窗口抖动、屏幕取色 |
| 展开 | 把输入区拉高 |
| 发送 | 旁边的小三角在 Enter 发送和 Ctrl+Enter 发送之间切换 |

输入区上沿可以上下拖，改变输入区和消息列表的高度，拖过的高度会记住。

字体可选雅黑、宋体、黑体、楷体，字号 12–24。代码卡片可以选语言、开关自动换行并复制。截图、滚动截图、录屏和屏幕取色使用浏览器的屏幕共享；提取文字依赖浏览器自带的文字识别，不支持时会提示。

### 联系人和个人

联系人分成在线和好友。在线的人可以直接打开单聊。好友需要对方同意；发出去的申请会显示已申请。

个人资料可以改昵称、个性签名、头像和头像挂件，也能看到自己这次连接的 IP。消息提醒和免打扰都在设置里。

### 管理页

`/admin` 使用单独的管理员账号，默认用户名是 `admin`。密码在服务第一次启动时生成，只印在本机终端或管理窗口里，不出现在聊天页。管理页可以看概览、用户和群。

### 服务管理壳

`desktop/` 是 Electron 窗口。安装包里带好服务程序，对方电脑不必再装 Go 或 Node。双击只打开管理窗口，点「启动」才开始监听。窗口里可以改端口、复制聊天地址和后台地址、在系统浏览器打开聊天或新账号、刷新局域网地址。关掉窗口会缩进托盘。

IP 变了之后点「刷新」。服务监听所有网卡，所以换地址不用重启进程。

## 构建前端

前端构建需要 Node 24。仓库里已安装的 Vite 8 不能在 Node 20.10 上运行。

```bash
export PATH="/usr/local/opt/node@24/bin:$PATH"
cd web && npm install && npm run build
```

`npm run build` 会把页面写进 `internal/web/dist`。带哈希的静态资源不入库，入库的 `index.html` 只是占位。要在服务里看到聊天页，先构建前端，再编译 Go。

## 编译并启动

在仓库根目录执行：

```bash
CGO_ENABLED=0 go build -o superlocal ./cmd/superlocal
./superlocal
```

常用参数：

```bash
./superlocal -addr :8080 -data ./data -max-upload 200MB
```

终端会打印聊天页地址、管理页地址、管理员账号，以及当前密码。把聊天地址发给同一网络里的人。管理地址只留在跑服务的这台机器上。

## 服务管理壳打包

打安装包的电脑需要 Go 和 Node 24。macOS 安装包在 Mac 上打，Windows 安装包在 Windows 上打。

macOS：

```bash
export PATH="/usr/local/opt/node@24/bin:$PATH"
CGO_ENABLED=0 go build -o desktop/binaries/superlocal ./cmd/superlocal
cd desktop && npm install && npm test && npm run pack
```

Windows 在 `cmd` 中：

```bat
set CGO_ENABLED=0
go build -o desktop\binaries\superlocal.exe .\cmd\superlocal
cd desktop && npm install && npm test && npm run pack
```

开发时可以不打包。先编译服务程序，再在 `desktop/` 执行 `npm start`。macOS 安装包没有签名，第一次打开时按系统提示允许该应用。
